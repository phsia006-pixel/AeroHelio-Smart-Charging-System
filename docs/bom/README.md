
# AeroHelio Bill of Materials

This directory documents the electrical and mechanical components selected for the AeroHelio senior design project.

## Component Selection

The design includes:

- ESP32-S3 microcontroller for monitoring and control
- INA226 sensors for voltage and current measurements
- Solar panel for renewable power generation
- DC motor and 3D-printed turbine for wind generation
- 3S lithium-ion battery for energy storage
- Voltage regulation and conversion circuitry
- Diodes, fuses, and other protective components

## Design Considerations

Components are selected based on power requirements, electrical compatibility, efficiency, size, cost, and safety.

The system requires regulated output power, reverse-current protection, and appropriate battery-charging circuitry.

## Project Status

The bill of materials is a working document. Some components and their specifications may change following subsystem testing and integration.

The BOM includes preliminary cost estimates and purchased components, but should not be interpreted as a fully validated final hardware configuration.
